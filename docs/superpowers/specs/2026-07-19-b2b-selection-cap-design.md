# B2B selection cap design

Обновлено: 2026-07-19.

## Цель

Мебельный B2B-проект разрешает выбрать до 10 товаров без фотографии пустой комнаты и до 9 товаров, если фотография задана.

## Решение

- `B2BProject` получает nullable-поле `sourceImageUrl`.
- В форме создания менеджер может необязательно загрузить фотографию через существующий `POST /files/upload`.
- API сохраняет URL фотографии и копирует его в общий `RoomProject` при запуске генерации.
- `PUT /manager/b2b-projects/:id/products` принимает максимум 10 UUID на DTO-уровне.
- Сервис проектов применяет фактический лимит: `sourceImageUrl ? 9 : 10` при сохранении подборки и повторно перед запуском.
- Worker независимо применяет то же правило перед обращением к AI-провайдеру.
- Manager UI показывает фактический лимит и блокирует выбор следующего товара после его достижения.

## Ошибки и совместимость

- Проекты без фотографии продолжают работать без миграции данных и получают лимит 10.
- Проекты с фотографией и десятью товарами отклоняются API до генерации.
- Marketplace flow не меняется.
- Фото необязательно; ошибка загрузки не создаёт B2B-проект с потерянной ссылкой.

## Проверка

- DTO принимает 10 UUID и отклоняет 11.
- API принимает 10 товаров без фото и отклоняет десятый товар с фото.
- Worker принимает 10 товаров без фото и отклоняет 10 с фото.
- UI ограничивает ручной выбор десятью или девятью товарами и передаёт загруженный URL при создании.
